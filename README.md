# DeViSE — visual–semantic learning

Live presentation: https://edwinleeh001.github.io/devise-presentation/

Video section: https://edwinleeh001.github.io/devise-presentation/#framework-video

A bilingual COMP6710 presentation about Frome et al., *DeViSE: A Deep Visual-Semantic Embedding Model* (NIPS 2013). Includes Chinese and English 20-second explainers, matching captions and transcripts, a framework diagram, and computed teaching examples.

This repository contains the static website published by GitHub Pages. The `.nojekyll` file preserves Next.js `_next` assets. All project assets use `/devise-presentation/` as their base path.

The videos and diagrams are educational illustrations, not measured training results. Narration is synthesized. Original papers and font licenses are included with their attribution.
