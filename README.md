# DeViSE — visual–semantic learning

Live presentation: https://edwinleeh001.github.io/devise-presentation/

Video section: https://edwinleeh001.github.io/devise-presentation/#framework-video

Figure 1 video (methodology): https://edwinleeh001.github.io/devise-presentation/#paper-figure-1-video

Figure 2 video (experimental evidence): https://edwinleeh001.github.io/devise-presentation/#paper-figure-2-video

A bilingual COMP6710 presentation about Frome et al., *DeViSE: A Deep Visual-Semantic Embedding Model* (NIPS 2013). Includes Chinese and English 20-second explainers for the overview and for each original Figure 1 and Figure 2 (six videos total), matching captions and transcripts, downloadable video storyboards and sources, a framework diagram, original paper Figures 1 and 2 with bilingual panel/case readings, complete Chinese and English speaking scripts with matching content and a shared 28-minute run of show plus 2-minute contingency, print-friendly A4 PDFs of both scripts with embedded fonts and the same timing and playback cues, an offline rehearsal pack containing both PDFs and all six videos, and computed teaching examples.

This repository contains the static website published by GitHub Pages. The `.nojekyll` file preserves Next.js `_next` assets. All project assets use `/devise-presentation/` as their base path.

Original Figures 1 and 2 and the reported tables are sourced paper evidence. The supplementary Anatomy slide-rule and animated overview are authored teaching aids; their illustrative or computed values are explicitly identified. Narration is synthesized. Original papers and font licenses are included with attribution.
